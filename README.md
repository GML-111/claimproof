# ClaimProof｜投资命题多证据验证器

## 在线体验
Web 产品 URL：https://modelscope.cn/studios/MLGuan/claimproof

## 产品简介
面向投资研究者，把投资命题拆成可验证子问题，调用真实数据形成支持、反对与无法验证的证据链，并给出条件化结论。目标用户是个人投资者、研究员和投顾运营人员。

## 本地启动
pip install -r requirements.txt
streamlit run app.py

## 环境变量
- DEEPSEEK_API_KEY
- FUYAO_API_KEY

## 数据来源
同花顺扶摇金融数据 API（行情快照、利润表）。所有数据展示均带来源、时点、单位、统计口径。

## AI 角色
- 拆解投资命题为可验证子问题
- 组织支持 / 反对 / 无法验证证据链
- 检测证据冲突与数据缺失
- 生成条件化结论（判断 + 不确定性 + 什么变化会改变结论）
- **不输出买卖建议、不承诺收益、不做确定性涨跌预测**

## 已知边界
- 目前仅接入扶摇 API 的行情快照和利润表两个工具
- iFinD MCP 预留接口但未接入
- 历史任务仅保存在会话中，页面刷新后不持久化
- 长上下文压缩目前只保留最近一次命题的数据包
- 数据缺失或接口失败时，产品会显示"无法验证"或错误提示，绝不静默生成"正常"结论

## 合规声明
本产品仅供研究参考，不构成任何投资建议。事实、推断与不确定信息已区分标注。数据缺失、冲突、过期或调用失败时，不生成"正常"结论。
