## 产品简介
面向投资研究者，把投资命题拆成可验证子问题，调用真实数据形成支持、反对与无法验证的证据链，并给出条件化结论。

## 本地启动
pip install -r requirements.txt
streamlit run app.py

## 环境变量
- DEEPSEEK_API_KEY
- FUYAO_API_KEY

## 数据来源
同花顺扶摇金融数据 API（行情快照、利润表）

## AI 角色
拆解命题、组织证据链、冲突检测、生成条件化结论。不输出买卖建议、不承诺收益。
